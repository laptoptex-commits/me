MY PERSONAL WEBSITE — JHON'S HAZA

CARA MEMBUKA
1. Ekstrak file ZIP ini.
2. Buka folder "my_personal_website".
3. Ketuk file index.html. Website akan terbuka di browser.
4. Jika menggunakan Acode: buka folder ini di Acode, lalu pilih index.html dan tekan Preview.

FOTO
Semua foto di folder assets adalah foto asli yang kamu kirim:
- profile.jpg = foto profil
- paskibra.jpg = dokumentasi Paskibra
- osis.jpg = dokumentasi OSIS
- classmates.jpg = foto teman sekelas

BAGIAN YANG MASIH PERLU KAMU LENGKAPI
- Di index.html, cari "Nama SMP" dan "Nama SD", lalu ganti dengan nama sekolahmu.
- Tambahkan tahun pendidikan jika ingin.
- Tombol WhatsApp saat ini membuka WhatsApp dengan pesan siap kirim, tetapi belum diarahkan langsung ke nomor pribadimu. Untuk mengarah langsung, ganti tautan https://wa.me/?text=... pada index.html menjadi https://wa.me/62xxxxxxxxxx (gunakan nomor dengan kode negara 62, tanpa angka 0 di depan).

CATATAN KOMENTAR
Guestbook saat ini menyimpan pesan di browser/perangkat yang dipakai. Komentar belum tersinkron ke semua pengunjung. Agar semua orang bisa saling melihat komentar, perlu ditambahkan database/layanan backend.

Website ini memakai Google Fonts jika internet tersedia; tanpa internet tetap bisa dibuka dengan font cadangan.
